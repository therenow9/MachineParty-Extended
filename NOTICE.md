# Notice: credit and provenance

**Machine Party** is a game by **Mike Klubnika** and **GDeavid**. The game, its code, scenes, art and every other asset are theirs. Thank you for making it.

Machine Party: Extended changes how the game plays and is built from the game's own scripts: decompiled, then modified so more people can play at once on one screen. Any part of this project that comes from the game's code is credited entirely to its makers. This project claims no ownership of it. Better Couch Lobby, More Cosmetics and GameCube Controller Support are this project's own code, and attach to the game through the mod loader's hooks.

This is an unofficial fan modification. It is not affiliated with, authorized by, sponsored by or endorsed by the game's developer or publisher.

## A legitimate copy is required

Nothing here is a copy of the game. You need your own legitimate Steam copy of Machine Party (Steam app 4108000) for any of it to run. Pirated copies are not supported, and piracy is strictly prohibited.
