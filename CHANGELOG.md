# Changelog

## 1.1.0 (in progress)

- **Chinese, Simplified and Traditional.** With the game set to either, Extended's own text follows it: the couch lobby cards, The Filter's scoreboard, Duck Hunt's two-hunter reveal, split-screen labels, GO shouts and hunter HUD, and the online refusal and room messages. GameCube Controller Support's two on-screen notes too, and its adapter warning now wraps instead of running off the screen.
- **The version is `mp-extended-1.1`,** shown after the game version in the main menu's bottom corner (`v2.1.2+mp-extended-1.1`) and in the refusal messages. Players on 1.0 and 1.1 can't join each other; players without Extended still can, at 4 or fewer.

First public release. The [README](README.md) lists what it adds and what changes in each minigame.
